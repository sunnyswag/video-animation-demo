### blocking-async-demo 使用说明

- 场景通过 URL 参数切换：`?scene=overview`（2×2 总览）/ `sync-blocking` / `sync-nonblocking` / `async-blocking` / `async-nonblocking` / `c-epoll`
- `空格` / `→` 下一步，`R` 重置，`C` 显示/隐藏代码（学习模式）
- 调试参数：`?steps=N` 自动推进 N 拍，`&code=1` 默认开启学习模式
